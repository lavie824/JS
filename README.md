# Skyline Build Royale

פרוטוטייפ 3D קטן בסגנון יריות ובנייה, בנוי כאתר סטטי עם Three.js.

## הרצה

פתח שרת סטטי בתיקייה הזו, ואז גלוש לכתובת שהוא מציג:

```powershell
node server.mjs
```

ואז:

```text
http://localhost:5173
```

## שליטה

- `WASD` movement
- Mouse aim
- Left click shoots or places the selected build
- Right click or `Q` toggles combat/build mode
- `1`, `2`, `3` rifle, shotgun, SMG
- `4`, `5`, `6` wall, ramp, floor
- `Space` jump
- `Shift` sprint with stamina
- `R` reload
- `Esc` pause/settings menu
